# Obsidian vs TriliumNext — сравнение систем управления знаниями

Организация личных знаний, заметок и идей становится все более важной задачей — будь вы разработчиком, исследователем или просто обывателем как я, который хочет навести порядок в той информации, которая сваливается на нас каждый день.  
Сегодня сравним **Obsidian** и **TriliumNext** — два популярных решения для ведения личной базы знаний (PKM, Personal Knowledge Management).

---

## Что такое Obsidian

Obsidian — это настольное приложение для ведения заметок и базы знаний, основанное на **Markdown-файлах**.  
Каждая заметка — это обычный `.md`-файл, который хранится локально, а связи между заметками формируют сеть идей.

![](353eed1b4d36384d57fafa0bdd31a980_MD5.png)

### Основные особенности:
- Работает на Windows, macOS, Linux, Android и iOS  
- Хранит данные **локально**, без облачной зависимости  
- Использует **ссылки между заметками** и граф визуализации  
- Поддерживает **плагины, темы, кастомизацию интерфейса**  
- Есть платные сервисы — **Obsidian Sync** и **Obsidian Publish**

### Преимущества:
- Простое хранение данных в открытом Markdown-формате  
- Огромная экосистема плагинов  
- Прекрасно подходит для концепции **“второго мозга”** (ну раз с первым разобрались) 
- Гибкость в организации знаний (теги, ссылки, graph view)

### Недостатки:
- Некоторые функции (синхронизация, публикация) — платные  
- Сложность для новичков из-за множества настроек  
- Зависимость от плагинов (риск несовместимости при обновлениях)
- Нельзя сказать, что это open-source решение
- Отсутствует официальный докер образ (я использовал от LinuxServer)

---

## Что такое TriliumNext

TriliumNext — это активно развиваемый **форк Trilium Notes**, ориентированный на **иерархическую организацию знаний**.  
В отличие от Obsidian, он использует базу данных и дерево (на самом деле не совсем древовидная структура, но за неимением другого обозначения, пусть будет дерево) заметок вместо отдельных файлов.

![](7edc24e9868988b9ca25592266c7dd3c_MD5.webp)

### Основные особенности:
- Полностью **open-source**, поддерживает **self-hosting**  
- Веб-интерфейс + десктопное приложение (есть клиенты под все три ОС) 
- Глубокая **иерархическая структура** заметок (дерево)  
- Поддержка **атрибутов, шаблонов, версий и клонирования (поэтому не совсем дерево)**  
- Возможность **синхронизации между устройствами** из коробки и бесплатно (Obsidian? Нет, не слышал)

### Преимущества:
- Мощная и гибкая структура базы знаний  
- Множество функций «из коробки» — диаграммы, кодовые блоки, формулы  
- Возможность размещения на своём сервере (Docker, NAS)  
- Подходит для продвинутых сценариев, корпоративных вики и knowledge bases

### Недостатки:
- Для кого-то может показаться более крутая кривая обучения 
- Интерфейс менее дружелюбен, чем у Obsidian (но это субъективно). Для тех кто привык к MS Word будет легко вкатиться.  
- Официального мобильного приложения нет. Интерфейс адаптирован под использование с мобильными устройствами.

## Сравнение по ключевым параметрам

| Параметр | **Obsidian** | **TriliumNext** |
|-----------|---------------|------------------|
| **Формат хранения** | Markdown-файлы локально | Встроенная база данных |
| **Организация знаний** | Сеть заметок и граф связей | Древовидная иерархия с атрибутами |
| **Простота старта** | Высокая — начать просто | Требует настройки и понимания структуры |
| **Расширяемость** | Плагины и темы от сообщества | Много встроенных функций |
| **Синхронизация** | Через Obsidian Sync (платно) или Git | Через встроенный сервер или WebDAV |
| **Мобильные приложения** | Полноценные клиенты iOS/Android | Браузер или экспериментальное приложение |
| **Self-Hosting** | Не обязателен | Рекомендуется для полного контроля |
| **Подходит для** | Индивидуальных заметок и идей, база знаний | Базы знаний, документации, корпоративных вики (но есть решения которые лучше подходят под последнюю задачу) |

| Возможность | **Obsidian** | **TriliumNext** |
|--------------|---------------|----------------|
| Markdown-редактор | ✅ | ✅ |
| Вложенные заметки | ⚙️ через папки | ✅ иерархически |

| Граф связей | ✅ | ⚙️ (через карту) |
| Встраиваемые изображения / файлы | ✅ | ✅ |
| Атрибуты заметок | ⚙️ через плагины | ✅ встроено |
| Версионирование | ⚙️ через Git / плагины | ✅ встроено |
| Шаблоны | ✅ через плагины | ✅ встроено |
| API / скрипты | ⚙️ через плагины | ✅ JS API встроено |

## Выбор: кому что подойдёт

| Сценарий | Рекомендация |
|-----------|---------------|
| Быстро начать, просто писать заметки | 🟩 **Obsidian** |
| Построить сложную базу знаний с иерархией | 🟩 **TriliumNext** |
| Работа с Markdown и внешними редакторами | 🟩 **Obsidian** |
| Self-Hosting, приватность, контроль | 🟩 **TriliumNext** |
| Встроенная синхронизация из коробки со всеми клиентами | 🟩 **TriliumNext** |
---

## Итог

**Obsidian** — идеален для тех, кто хочет гибкую, эстетичную и лёгкую в освоении систему заметок.  
**TriliumNext** — больше подходит тем, кто стремится к построению **структурированной базы знаний** с полным контролем над данными и мощными встроенными возможностями.

> 💡 Совет от prohomelab: если вы хотите начать с инструмента для использования которого есть много видео — начните с Obsidian.  
> Если есть потребность в мощной иерархии, шаблонах, а, лишние, откровенно говоря, красивости вас только раздражают — переходите на TriliumNext.
